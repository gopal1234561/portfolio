# 🌐 Personal Portfolio Website
A modern, responsive portfolio website showcasing my skills, projects, education, and achievements. Built to provide recruiters and developers with a quick overview of my technical expertise and experience.
## 🚀 Live Demo
https://portfolio-dun-seven-12.vercel.app/
## 📌 Features
- Responsive design for all devices
- About Me section
- Skills showcase
- Projects with live demo and source code
- Education details
- Contact section
- Smooth animations and modern UI
- Fast loading and optimized performance
## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- React.js
- Tailwind CSS
- Vite
- Vercel

## ⚙️ Installation
Clone the repository

```bash
git clone <your-github-repository-url>
```

Move into the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build the project
```bash
npm run build
```
Preview production build

```bash
npm run preview
```
